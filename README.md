# hdf5-viewer

HDF5 tree explorer with collapsible group hierarchy, dataset preview, and attribute display.

## Features

- Collapsible tree view of HDF5 groups and datasets
- Dataset shape, dtype, and size display
- Preview first 100 elements of selected datasets
- Attribute key-value display for groups and datasets
- Group and dataset icons for visual distinction
- h5ad (AnnData) structure recognition (obs, var, X, layers, etc.)
- Powered by jsfive (pure JavaScript HDF5 reader)

## Supported Extensions

- `.h5ad`
- `.h5`
- `.hdf5`

## Installation

Install from the **Plugins** tab in the AutoPipe desktop app.
